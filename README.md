# おかえり、志摩中。

糸島市立志摩中学校の同級生が、懐かしい再会をきっかけに、これからも安心してつながれる場をつくるための同窓会プロジェクトです。

> 懐かしさを、未来のつながりへ。

## 目指すもの

- 加也小・引津小・桜野小から集まった仲間が、もう一度ゆるくつながる
- 今どこに住んでいても、糸島へ帰ったときに「おかえり」と言える関係をつくる
- 糸島の自然・観光・お店・仕事・地域活動を、同級生の視点で再発見する
- Uターン、親の介護、子育て、実家や空き家など、人生の節目に相談できるつながりを育てる

初回は社会課題の解決を目的にしすぎず、まずは安心して再会し、「また会いたい」と思える場をつくることを大切にします。

## 開催概要（検討中）

- 開催時期：2026年12月〜2027年1月
- 会場候補：初音旅館／グローカルホテル糸島
- 連絡方法：LINEを中心に運用
- 対象：糸島市立志摩中学校の同級生
- 出身小学校：加也小学校／引津小学校／桜野小学校 ほか

## 運営の基本構成

```text
LINE
  ↓ 公式案内を送付

公開サイト
  ↓ 出欠・希望調査フォーム

Googleフォーム
  ↓ 回答を自動保存

Googleスプレッドシート
  出欠・連絡状況・小学校別集計

GitHub
  企画、タスク、公開サイトの更新履歴を管理
```

## AI・デジタル活用

AIを目立たせること自体を目的にせず、幹事の負担を減らし、参加者が安心できる運営に活用します。

- LINE案内文やリマインド文の作成補助
- アンケート回答の匿名集計・要約
- 糸島の思い出やおすすめスポットの可視化
- 当日のスライド、クイズ、進行台本の作成
- サイトや運営資料の更新支援

個人を特定できる情報を、本人の同意なく生成AIへ入力しません。

## 安心して参加するための方針

本会は、旧友との交流と地域のつながりづくりを目的としています。

- 宗教、政治、ネットワークビジネス、商品販売などの勧誘を目的とした参加は禁止します
- 出欠名簿や連絡先などの個人情報はGitHubへ保存しません
- 写真や氏名の公開は、本人の同意を確認します
- LINEグループへの参加は希望者のみとします
- 取得した情報は同窓会運営以外の目的で利用しません

詳細は [PRIVACY.md](./PRIVACY.md) に整理します。

## 当面のゴール

1. 幹事と各小学校の連絡担当を決める
2. 同窓会の目的と案内文を固める
3. 開催候補日・会場・予算を比較する
4. Googleフォームで開催希望調査を行う
5. 小規模に案内を試し、反応を見ながら広げる
6. 公開用のシンプルな公式サイトを準備する

# あつまれ島中学校｜同窓会サイト公開デモ

> [!IMPORTANT]
> このリポジトリは、同窓会サイトの企画・UI・仕組みを紹介するための公開デモです。
> 登場する学校名、人物名、担任名、回答データはすべて架空です。実在する学校・人物・団体とは関係ありません。

## 公開デモ

https://agile-drummer.github.io/shima-reunion-demo/

## デモの設定

舞台は、海に囲まれた架空の学校「あつまれ島中学校」です。

- サイト名：あつまれ島中学校
- 出身小学校：どんぐり小／しおかぜ小／こもれび小
- 担任：フクロウ先生／カモメ先生／ヤギ先生
- 幹事代表：しま長 ポンきち
- 幹事メンバー：モコ／ペンタ／コンタ
- 写真下の表記：DONGURI ISLAND

名称は、のんびりした島暮らしを感じる架空設定です。特定作品の公式キャラクター、ロゴ、画像素材は使用していません。

## デザイン方針

もともとの同窓会サイトが持つ、落ち着いた白ベースのデザインと写真中心の構成を保っています。

- 元のレイアウトと雰囲気を維持
- 固有名詞だけを架空設定へ変更
- ファーストビューの写真は先頭2枚のみ使用
- スマートフォン優先
- 過度にゲーム風へ寄せない

## 参加意向フォーム

公開デモでは架空の名簿だけを検索できます。

```text
どんぐり小
1組・フクロウ先生
モコ
```

回答内容は外部APIやGoogleスプレッドシートへ送信せず、利用中のブラウザの `localStorage` にだけ保存します。

## 公式LINE・運営画面デモ

公開サイトの最下部から、次の操作を試せます。

- LINE風トーク画面と6分割リッチメニュー
- リッチメニューから遷移するロール別運営メンバーログイン
- 4クラス・100人の架空名簿の絞り込み
- 担当者、参加状況、連絡状況の更新
- 参加意向の横棒グラフ
- 公式LINE友だちタグ

運営画面のURL：

https://agile-drummer.github.io/shima-reunion-demo/organizer/

認証やLINE連携は実行せず、操作状態はブラウザの `localStorage` に保存します。

## 本番版との分離

| 項目 | 公開デモ | 本番版 |
|---|---|---|
| 配信 | GitHub Pages | Cloudflare Pages |
| リポジトリ | Public | Private |
| データ | 架空のダミーデータ | 限定共有データ |
| 保存 | localStorage | Pages Functions経由 |
| LINEログイン | 画面上のモック | LINE Login API |
| 公式LINE | 追加済み表示のモック | LINE公式アカウント |
| 認証情報 | なし | Cloudflare Secrets |

本番版の名簿、回答データ、個人情報、秘密鍵は、この公開リポジトリには保存しません。

## 安全方針

- 実名、電話番号、メールアドレス、LINE IDを保存しない
- 実在する名簿をブラウザへ配信しない
- 本番用の秘密鍵や環境変数をコミットしない
- 特定作品の公式素材を転載しない

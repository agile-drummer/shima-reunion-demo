# おかえり、志摩中。

糸島市立志摩中学校の同級生が、懐かしい再会をきっかけに、これからも安心してつながれる場をつくるための同窓会プロジェクトです。

> 懐かしさを、未来のつながりへ。

## 目指すもの

- 加也小・引津小・桜野小から集まった仲間が、もう一度ゆるくつながる
- 今どこに住んでいても、糸島へ帰ったときに「おかえり」と言える関係をつくる
- 糸島の自然・観光・お店・仕事・地域活動を、同級生の視点で再発見する
- Uターン、親の介護、子育て、実家や空き家など、人生の節目に相談できるつながりを育てる

初回は社会課題の解決を目的にしすぎず、まずは安心して再会し、「また会いたい」と思える場をつくることを大切にします。

## 開催概要（検討中）

- 開催時期：2026年12月〜2027年1月
- 会場候補：初音旅館／グローカルホテル糸島
- 連絡方法：LINEを中心に運用
- 対象：糸島市立志摩中学校の同級生
- 出身小学校：加也小学校／引津小学校／桜野小学校 ほか

## ツールの役割分担

このGitHubリポジトリは、参謀役が企画・仕組み・公開物を整理するために利用します。幹事全員の日常的な共有場所にはNotionを使います。

| ツール | 役割 | 主な利用者 |
|---|---|---|
| LINE | 日々の連絡、通知、同級生への案内 | 幹事・参加者 |
| Notion | 決定事項、タスク、会議メモ、会場比較 | 幹事全員 |
| Googleフォーム | 開催希望調査、正式な出欠回答 | 同級生 |
| Googleスプレッドシート | 氏名、連絡状況、出欠などの限定管理 | 必要最小限の幹事 |
| GitHub | 企画設計、AI活用、公開サイト、変更履歴 | 参謀役 |

```text
LINE
  日々の連絡・通知
       ↓

Notion
  幹事用ポータル・タスク・議事録
       ↓                         ↓

Googleフォーム              GitHub
  希望調査・出欠回答          企画設計・公開サイト
       ↓

Googleスプレッドシート
  個人情報・出欠管理
```

### 情報の正本

- 幹事の決定事項・タスク：Notion
- 個人情報・出欠：Googleスプレッドシート
- 公開サイトのソース・技術作業：GitHub
- 日々の会話・通知：LINE

LINEで決まった重要事項はNotionへ残します。氏名・電話番号・LINE IDなどの個人情報は、NotionやGitHubへ掲載しません。

## GitHubの運用方針

GitHubは参謀役専用とし、Discussionは当面利用しません。

Issueでは、次のような「仕組みを作る仕事」を管理します。

- Notionの設計・改善
- Googleフォームや集計方法の設計
- LINE案内文とFAQの整備
- 公開サイトの制作
- AI活用の企画
- 運営全体の振り返り

誰が会場へ連絡するか、次回幹事会の日程、各小学校の進捗など、日々の運営タスクはNotionで管理します。

## AI・デジタル活用

AIを目立たせること自体を目的にせず、幹事の負担を減らし、参加者が安心できる運営に活用します。

- LINE案内文やリマインド文の作成補助
- アンケート回答の匿名集計・要約
- 糸島の思い出やおすすめスポットの可視化
- 当日のスライド、クイズ、進行台本の作成
- サイトや運営資料の更新支援

個人を特定できる情報を、本人の同意なく生成AIへ入力しません。

## 安心して参加するための方針

本会は、旧友との交流と地域のつながりづくりを目的としています。

- 宗教、政治、ネットワークビジネス、商品販売などの勧誘を目的とした参加は禁止します
- 出欠名簿や連絡先などの個人情報はGitHubへ保存しません
- 写真や氏名の公開は、本人の同意を確認します
- LINEグループへの参加は希望者のみとします
- 取得した情報は同窓会運営以外の目的で利用しません

詳細は [PRIVACY.md](./PRIVACY.md) に整理します。

## 当面のゴール

1. 幹事共有用のNotionを作る
2. 幹事と各小学校の連絡担当を決める
3. 同窓会の目的と案内文を固める
4. 開催候補日・会場・予算を比較する
5. Googleフォームで開催希望調査を行う
6. 小規模に案内を試し、反応を見ながら広げる
7. 公開用のシンプルな公式サイトを準備する
